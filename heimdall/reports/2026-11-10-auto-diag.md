## Corsa D 2011 — antibrouillards avant
- Option dans le BCM (Tech2 : « BC »), réglage « Variant Configuration ». Chemin Tech2 : Body > BC > Programming > Variant configuration programming > Enter security code (Car Pass 4 chiffres requis). Même chemin dans OP-COM/Vauxcom.
- Relais K39 (antibrouillards avant), fusible FU7 dans l'UEC (boîte moteur) ; si le fil BCM → K39 manque, le codage ne suffit pas.
- Protocole GMLAN (GMW3110) sur ISO-TP 11 bits : $10/$1A/$3B/$27/$3E/$28/$AE. IDs du BCM, DIDs, format du bloc de config et dérivation Car Pass → clé $27 : NON publics → capturer une session OP-COM au sniffer, puis rejouer.
- Bus : HS-CAN 500k (6/14) sûr ; MS-CAN 95,2k (3/11) et SW-CAN 33,3k (pin 1) probables, à confirmer en écoute passive.
- Sécurité : chargeur batterie > 12,5 V, sauvegarde complète de la config avant écriture, un seul paramètre, JAMAIS « BCM reset » (antidémarrage).

## Adaptateurs
- OBDLink EX (USB, STN, ~70 $) : HS + MS-CAN, débit libre → diag + codage Windows/Pi. (MX+ ~120 $ en Bluetooth ajoute le SW-CAN.)
- CANable 2.0 candleLight (~35 $ + câble OBD→DB9) : CAN brut, SocketCAN sur Pi, sans pilote sous Windows → sniffer.
- Clone OP-COM (~40 €) : une seule fois, pour faire le codage pendant que le CANable enregistre.
- ELM327 clones : lecture OK, écriture risquée (débit 95,2k mal géré, BUFFER FULL).
