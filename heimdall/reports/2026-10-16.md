# Digest Heimdall — 2026-10-16

> Premier digest (amorçage). Veille de la Super_Toolbox sur les 6 domaines. Tout est vérifié (repos existants,
> actifs 2025-2026). Licences majoritairement permissives ; les exceptions sont signalées. Rien ne double l'existant.
> Format : **Nom** — `owner/repo` · licence · ce que ça fait + pourquoi c'est pertinent.

## À retenir (résumé)

- **Alphred (IA locale)** : la pile vocale/mémoire open-source a beaucoup mûri — **Kokoro** (TTS), **faster-whisper** (STT), **Mem0** (mémoire longue), et côté dev **Serena** + **Context7** (MCP qui boostent Claude Code).
- **Panels Godot en code** (fil rouge) : **godot_state_charts**, **limbo_console** (console de debug in-game sans éditeur) et **gdscript-toolkit** (lint/format CLI) servent *tous* les projets à panel.
- **Stryder (coop physique)** : **godot-rollback-netcode** (snopek, la référence) et **Softbody2D** comblent les manques netcode/soft-body.
- **Modding** : **Frida**, **Harmony**, **MelonLoader**, **FModel**, **UABEA**, **ida-pro-mcp** complètent universal-modder/rea.
- **Audit défensif** : **RustScan**, **Nuclei**, **Lynis**, **CrowdSec**, **Cameradar** (caméras RTSP) — tout en cadre défensif/hardening.
- **Dev/QOL** : **uv** (Python tout-en-un), **Textual** (TUI), **Nuitka** (packager les panels Python en .exe).

## Godot & création de jeux  [godot]

- **Godot State Charts** — `derkork/godot_state_charts` · MIT · machines à états hiérarchiques/parallèles (IA, UI, flux) ; se pilote 100 % en code → idéal pour les panels datapad.
- **LimboConsole** — `limbonaut/limbo_console` · MIT · console de debug in-game (commandes, autocomplétion) ; parfait pour déboguer des builds **sans éditeur**. Même auteur que limboai (déjà copié).
- **gdscript-toolkit** — `Scony/godot-gdscript-toolkit` · MIT · linter + formateur CLI (gdformat/gdlint) ; indispensable pour un workflow « tout en code » + CI.
- **Dialogue Manager** — `nathanhoad/godot_dialogue_manager` · MIT · dialogues branchés (GDScript + C#), Godot 4.4+, très utilisé.
- **Dialogic 2** — `dialogic-godot/dialogic` · MIT · dialogues/visual-novels clé en main, Godot 4.3+.
- **Maaack's Game Template** — `Maaack/Godot-Game-Template` · MIT · menus/options/crédits/save prêts à brancher.

## Physique & multijoueur temps réel  [physique-netcode]

- **Godot Rollback Netcode** — `snopek-games/godot-rollback-netcode` (GitLab) · MIT · rollback + prediction de référence pour Godot 4 ; base éprouvée pour du coop déterministe.
- **Delta Rollback** — `BimDav/delta-rollback` (GitLab) · MIT · addon rollback plus rapide/récent (v0.11), Godot 4.2+ ; alternative légère.
- **Softbody2D** — `Nolkaloid/godot-softbody2d` · MIT · soft bodies 2D (ressorts/points) ; pour le « tout est physique » (déformation, blobs, cordes).
- **Nakama** — `heroiclabs/nakama` · Apache-2.0 · serveur de jeu (auth, matchmaking, realtime, storage) + SDK Godot ; backend coop/persistance (lien, lourd).
- **GekkoNet** — `HeatXD/GekkoNet` · MIT · lib rollback netcode C++ moderne (2024-2025), bindings multi-moteurs.
- **GGPO** — `pond3r/ggpo` · MIT · SDK rollback P2P de référence (C/C++), brique bas niveau.

## Modding & reverse engineering  [modding-re]

- **Frida** — `frida/frida` · wxWindows (libre) · instrumentation dynamique / hooking multi-plateforme (JS injecté) ; incontournable pour modding runtime et RE.
- **Harmony** — `pardeike/Harmony` · MIT · patch runtime de méthodes .NET/C# (via BepInEx/MelonLoader) ; standard du modding Unity.
- **MelonLoader** — `LavaGang/MelonLoader` · Apache-2.0 · mod loader universel Unity (Mono + IL2CPP) ; complément à BepInEx.
- **FModel** — `4sval/FModel` · GPL-3.0 · explorateur/extracteur d'assets Unreal (.pak/.utoc) ; référence UE (lien, GPL → pas de subtree).
- **UABEA** — `nesrak1/UABEA` · MIT · édition/extraction d'assets et bundles Unity ; complément à AssetRipper.
- **IDA Pro MCP** — `mrexodia/ida-pro-mcp` · MIT · serveur MCP exposant IDA à un agent/Claude (décompilation, xrefs, renommage) ; nouveauté RE 2025.

## Agents IA, MCP & LLM local  [ia-agents]

- **Serena** — `oraios/serena` · MIT · serveur MCP « IDE pour agents » (outils symboliques via LSP) ; booste Claude Code sur gros codebases.
- **Context7** — `upstash/context7` · MIT · MCP qui injecte la doc à jour des libs ; réduit les hallucinations d'API.
- **Pydantic AI** — `pydantic/pydantic-ai` · MIT · framework d'agents typé (outils, structured output, multi-modèles dont Ollama) ; propre pour le majordome local.
- **Kokoro** — `hexgrad/kokoro` · Apache-2.0 · TTS local 82M, qualité élevée, CPU-friendly ; voix de l'assistant (Sonnette).
- **faster-whisper** — `SYSTRAN/faster-whisper` · MIT · STT Whisper (CTranslate2, 4× plus rapide, moins de VRAM) ; écoute vocale locale.
- **Mem0** — `mem0ai/mem0` · Apache-2.0 · mémoire longue durée pour agents (extraction + vectoriel) ; mémoire persistante du majordome. _(alt RAG : `HKUDS/LightRAG`, MIT)_

## Sécurité, réseau & audit défensif  [secu-reseau]

> Cadre strictement **défensif / audit autorisé / hardening** (voir lignes rouges de WifiSentinel et Kali-Pi).

- **RustScan** — `RustScan/RustScan` · GPL-3.0 · scan de ports ultra-rapide qui chaîne vers Nmap ; inventaire réseau express (lien, GPL).
- **Nuclei** — `projectdiscovery/nuclei` · MIT · scanner de vulnérabilités à templates YAML (CVE, mauvaises configs) ; auditer puis patcher **ses propres** services.
- **Lynis** — `CISOfy/lynis` · GPL-3.0 · audit de durcissement système (Linux/Pi) + rapport de remédiation ; 100 % hardening (lien, GPL).
- **CrowdSec** — `crowdsecurity/crowdsec` · MIT · IDS/IPS collaboratif léger (détection comportementale + bouncers) ; défense continue sur Pi/routeur.
- **Cameradar** — `Ullaakut/cameradar` · MIT · découverte de caméras RTSP + test des routes/credentials par défaut ; inventorier et **sécuriser ses** caméras.
- **nzyme** — `nzymedefense/nzyme` · SSPL (source-available) · WiFi/Ethernet Defense System (WIDS : rogue AP, attaques connues) ; pile défensive sans-fil (lien, licence restrictive → jamais en subtree).

## Outils dev, CLI/TUI, automatisation & QOL  [devtools]

- **uv** — `astral-sh/uv` · Apache-2.0/MIT · gestionnaire Python tout-en-un ultra-rapide (venv, deps, lock, `uvx`) ; remplace pip/venv/pipx.
- **Textual** — `Textualize/textual` · MIT · framework TUI Python (widgets, CSS, layout, souris) ; pour de beaux panels/TUI côté Python.
- **Gum** — `charmbracelet/gum` · MIT · composants interactifs (prompts, spinners, choix) pour scripts shell/PowerShell.
- **lazygit** — `jesseduffield/lazygit` · MIT · TUI Git complète ; QOL quotidienne.
- **yazi** — `sxyazi/yazi` · MIT · gestionnaire de fichiers TUI en Rust (async, preview) ; rapide et moderne.
- **Nuitka** — `Nuitka/Nuitka` · Apache-2.0 · compile Python → exécutable natif ; packager les panels Python en .exe (type Control_Panel).
